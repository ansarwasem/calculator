# ⚡ OmniCalc Pro - Ultra Modern Web Calculator

A stunning, ultra-fast, and feature-rich Scientific Web Calculator built with pure HTML5, CSS3, and modern JavaScript.

![OmniCalc Preview](screenshot.png)

## ✨ Features

- 🎨 **5 Ultra-Attractive Color Themes**:
  - **Aurora Glow**: Electric Neon Violet, Cyan & Pink with dynamic glowing orbs.
  - **Sunset Aura**: Warm Coral, Orange & Purple neon gradients.
  - **Cyber Mint**: Matrix-inspired deep emerald & glowing mint.
  - **Candy Pop**: Cheerful and playful vibrant candy tones.
  - **OLED Stealth**: Deep luxury titanium black with warm amber accents.
- 🔬 **Dual Mode**:
  - **Basic Mode**: Clean, streamlined interface for daily quick math.
  - **Scientific Mode**: Expandable panel with trigonometry, roots, powers, logs, and factorials.
- 🧮 **All Operations Supported**:
  - Basic arithmetic: `+`, `−`, `×`, `÷`, `%`, `mod`
  - Advanced operations: powers ($x^y$, $x^2$, $x^3$), roots ($\sqrt{x}$, $\sqrt[3]{x}$), reciprocal ($1/x$), absolute value ($|x|$)
  - Trigonometry: `sin`, `cos`, `tan`, `sin⁻¹`, `cos⁻¹`, `tan⁻¹` with DEG/RAD switch
  - Logarithms & Constants: `log₁₀`, `ln`, $\pi$, $e$
  - Factorials: $n!$
  - Parentheses: `(` and `)`
  - Memory: `MC`, `MR`, `M+`, `M−`, `MS`
  - Sign toggle: `±`
- 🔊 **Interactive Sound & Haptics**: Synthesized click, tone, and clear audio feedback powered by Web Audio API (with mute toggle).
- 📜 **Calculation History**: Keep track of previous calculations, click to recall, and clear when done.
- 📋 **Copy to Clipboard**: One-click instant copy button with toast notification.
- ⌨️ **Physical Keyboard Support**: Full support for keyboard input (numbers, operators, backspace, enter, esc).
- 📱 **100% Responsive**: Looks magnificent on desktop, tablet, and mobile screens.
